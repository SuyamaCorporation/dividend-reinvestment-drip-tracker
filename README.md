# DRIP Dividend Reinvestment Growth Tracker

## 概要
配当再投資（DRIP）戦略の複利成長をシミュレーションするツール。配当利回り・増配率・株価上昇率・月次追加投資額を入力し、DRIP有無の比較グラフと年次詳細テーブルを生成。

## 機能
- 入力パラメータ
  - 初期投資額・株価・配当利回り・増配率・株価上昇率・投資期間（最大50年）・月次追加投資
- 計算・表示
  - 年次複利シミュレーション（DRIP有 vs DRIP無し）
  - サマリ統計: 最終評価額・再投資配当合計・CAGR・乗数（倍率）
  - Canvas 折れ線グラフ: DRIP vs No DRIP vs コスト基準
  - Canvas 棒グラフ: 年次配当収入の成長
  - 年次詳細テーブル（株価・株数・配当収入・評価額・総リターン%）
- CSV エクスポートボタン

## 使い方
1. パラメータを入力して「Calculate」をクリック
2. グラフで長期複利効果を確認
3. テーブルで年次詳細を確認
4. 「Export CSV」でデータをダウンロード
